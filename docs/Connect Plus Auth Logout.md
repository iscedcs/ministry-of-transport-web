### Planner Response

Yes, absolutely! There are **3 easy ways** to pull the `accessToken` for your currently logged-in user:

---

### Option 1: Live API Endpoint (Fastest for Postman & cURL)
I created a helper endpoint in the app:
👉 **`GET http://localhost:3000/api/auth/token`** *(or whatever port your dev server is running on)*

Simply visit that URL in your browser while logged in, and it will return a JSON response containing your full access token:

```json
{
  "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6...",
  "bearerToken": "Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6...",
  "user": { ... },
  "willExpireAt": "2026-07-30 18:00:00"
}
```

---

### Option 2: Server Action in Code
You can import `getAuthInfo` directly from [`actions/auth.ts`](file:///c:/Users/TKT/codebase/isce/ecosystem/connect-web/actions/auth.ts):

```typescript
import { getAuthInfo } from '@/actions/auth'

const auth = await getAuthInfo()
if ('accessToken' in auth) {
  console.log('Access Token:', auth.accessToken)
}
```

---

### Option 3: Browser Developer Tools
1. Open DevTools (**F12** or **Right Click -> Inspect**).
2. Go to the **Application** tab -> **Cookies** -> Select `http://localhost:3000`.
